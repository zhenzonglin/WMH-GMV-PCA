# WMH-GMV-PCA 统计分析方案

版本：1.0；日期：2026-10-30。性质：预设方法与执行规范，不是已完成的队列结果。分析代码及参数变化必须记录版本，研究结果与软件合成验证分别报告。

## 研究问题与人群

研究WMH和GMV相对于健康参考的空间分布，是否在年龄、临床因素和全脑总量之外与一年功能结局、随访mRS变化及急性病灶位置的作用差异相关。关联解释为主，预测表现为辅；不作治疗获益或因果效应推断。

LS为健康参考队列；C3为发现及模型开发队列；GB为独立关联复现和固定预测模型验证队列。主要分析年龄50–75岁，纳入符合条件的基线MRI患者，包括确认的院内死亡。年龄范围外记录保留，但不把超范围投射当作已经验证的健康参考结果。

输入使用已处理的WMH20、原始GM119和真实ICV。接受已有WMH病灶重叠处理，不再次处理，也不排除GMV被急性病灶累及的区域。不开展多中心矫正，不加入中心及MRI距发病时间，不开展条件失配、脑龄和SuStaIn。

## 数据管理与分母

ID按字符串读取，以队列加ID连接，保留前导零。每个阶段冻结输入名单，分别报告计划人数、可用人数、失败、不适用与原因。表格中的列存在不等于变量可用；监测区分字段不存在、缺失、非法编码和来源冲突。实际人数与缺失率由远程数据生成，不从本地示例推断。

WMH和GMV统一为mL。ICV不得用非脑室组织体积替代。WMH20之和只有在覆盖范围核实后才能称全脑WMH总量；优先使用既有校正掩膜对应的全脑统计。GM119须使用官方纯GM标签集合，不能沿用混入非GM结构的旧宏区体积。

## 健康偏离

WMH逐区域在LS拟合GAMLSS零调整Gamma模型。正值均值为年龄自然样条3自由度、性别和log(ICV)的函数；零点概率由年龄线性项及性别解释；尺度首版为常数。全部为正值时使用同框架Gamma模型。正值数量低于配置阈值的区域标记参考不足，全零区域不拟合正值分布。

零值用条件分布质量的中点，即u=π/2；正值使用完整条件CDF。偏离为Φ⁻¹(u)，保留正负值并记录CDF截尾。含零点质量时中点分位分数不严格服从标准正态，因此不能据单个Z阈值作诊断。

GMV对log区域体积拟合GAMLSS正态位置尺度模型，均值包含年龄自然样条3自由度、性别和log(ICV)，尺度首版为常数。保存Z=(观察值−条件均值)/条件SD及D=−Z；D为正式分析方向，正值表示体积低于健康参考。保留负值，不先扣除全脑GMV。

LS五折交叉验证用于检查零概率校准、正值分布、预测区间覆盖率及年龄/性别分层表现。完成诊断后用全部合格LS拟合最终模型。不可估计、拟合失败、校准异常分别报告，不能把收敛当作校准良好。

方法实现：[GAMLSS](https://github.com/gamlss-dev/gamlss)与[gamlss.dist](https://github.com/gamlss-dev/gamlss.dist)。健康参考用于条件分布描述，不以卒中临床结局调参。

## 独立空间模式与联合表型

在C3中分别对WMH和GMV有符号偏离做PCA，中心化、不再次单位方差缩放、不白化。使用[FactoMineR](https://github.com/husson/FactoMineR)。WMH20和GM119不强行逐区配对。

维数候选0–10，受实际矩阵秩限制。[missMDA](https://github.com/husson/missMDA)采用EM方法，每次随机遮蔽5%单元，重复100次，输出遮蔽预测误差。该验证是矩阵单元验证，不是患者层面临床交叉验证，也不是一标准误规则。

每个候选维数进行200次患者bootstrap，检查载荷、投射得分和子空间稳定性。预设标准：最大子空间夹角中位数≤15°、95百分位≤30°；可单独识别成分的载荷相似度中位数≥0.90、得分ICC≥0.80。相邻特征值比小于1.10按近简并组解释，不在组内任意截断或赋予稳定单轴名称。这些是项目操作标准，不是通用临床阈值。

在满足稳定性标准的候选中选遮蔽误差最低维数，同误差选更小维数。K=0允许；无稳定结构不通过反复换算法强求阳性结果。

联合表型为 F=[TW/sW,TG/sG]，其中sW和sG为C3各模态保留得分总方差的平方根。保存原得分、C3标准化得分及模态平衡后的连续向量。此规则为透明缩放和拼接，不声称是独立验证的命名算法，不强行压为一个总分。

冻结LS模型、C3载荷、区域顺序、维数、均值及缩放。GB只投射；不因GB结果重新选成分。临床内部验证需要在C3每个训练折重新拟合所有依赖C3的步骤，不能拿全样本PCA结果直接声称完全无泄漏的预测验证。

## 急性病灶位置表征

使用已提供的急性二值掩膜。固定Harvard–Oxford侧化皮层及皮层下灰质/脑干、JHU20概率束和FSL小脑图谱，记录来源、模板、标签、许可和哈希。相同体素大小或都称MNI不等于模板相同；仅在模板兼容后进行所需网格重采样，标签使用最近邻，概率使用连续插值。

区域负荷 rᵢⱼ=ΣLᵢ(v)Aⱼ(v)/ΣAⱼ(v)，概率图谱采用概率加权受累比例。报告未覆盖病灶比例，不声称所有体素具有同等可靠的标签。

C3对每个区域负荷用log1p总病灶体积的3自由度自然样条回归，残差独立PCA；候选维数0、1、2并验证稳定性。该得分称“体积调整后的急性位置维度”；负残差表示同体积下该区域受累少，不表示负损伤。全部变换冻结用于GB。

区域降维与WMH交互的研究框架参考[Bonkhoff等，2022](https://pubmed.ncbi.nlm.nih.gov/35803717/)。本项目残差PCA和联合表型是预设设计，不能把既往文献当作本队列交互必然阳性的证据。

## B1一年mRS

主要终点为12个月mRS 0–6。确认死亡编码6；失访不编码为死亡。清洗字段与原始字段同时保留，冲突记录单列。数据满足要求即执行，缺字段时等待输入，不自动删协变量或插补。

使用[ordinal::clm](https://github.com/runehaubo/ordinal)累积logit模型。预设调整集包括年龄、性别、卒中前mRS、入院NIHSS、既往卒中、高血压、糖尿病、房颤、静脉溶栓及EVT。年龄和NIHSS使用3自由度自然样条；卒中前mRS采用逐分线性调整。M0为临床模型；M1加入ICV及WMH/GMV总量；MW、MG分别加对应空间成分；MWG加两组空间成分。比较使用相同完整病例集。

主要检验为MWG相对M1的联合空间块增量。报告每C3标准差的较差mRS共同OR、95%区间及完整mRS概率分布。检查比例优势，补充部分比例优势敏感性分析，保留原模型结果。估计失败、秩不足或缺少结局等级时不自动简化模型。

log(ICV)、log1p(WMH总量)、log(GMV总量)以及B2的log1p急性体积采用C3均值/SD标准化，参数固定后用于GB。该可逆参数化改善数值尺度，不改变模型拟合空间或变量集合；体积效应亦按1个C3标准差解释。临床内部验证的中心和尺度只能在对应训练折估计。

GB固定表征和公式后重新估计关联；另外用C3固定系数输出预测。两者明确区分。预测输出包括有序RPS、log loss、累积阈值校准及P(mRS≤2)。相同数据拟合后的性能标记为表观性能，不能冒充内部或外部验证。

## B1纵向mRS

保留3、6、12个月全部mRS等级，使用ordinal::clmm患者随机截距模型。访视作为分类变量，3个月参照；包括两组PC、访视及PC×访视。首版不加入随机斜率，按配置比较求积点数。

确认死亡仅向后补全mRS=6，不填充死亡之前未知状态。允许间歇缺失，保留现有访视记录，解释依赖可忽略缺失及模型假设。该模型描述总体功能与死亡状态的纵向关联；不解释为死亡吸收过程、状态转移概率或纯神经恢复速度。报告条件OR，不能把随机截距为零的概率称人群平均概率。

## B2位置与慢性结构交互

一年mRS使用同一有序回归框架。保留临床调整、全脑结构总量、急性总体积样条、全部慢性PC及急性位置主效应。主要位置交互为最多2个急性位置维度×WMH和GMV各前2个可识别稳定成分，最多8项；同时保留体积×同一慢性成分以区分总量调节。

主要检验为增加位置交互块相对加性及体积交互模型的增量。报告交互系数、区间及实际数据支持范围内的预测概率。近简并组不截断，不按临床P值选择交互。位置维度不足或不可稳定估计时如实报告，不自动换成更容易显著的部位定义。

## 多重比较、缺失与B3/B4

不把五项主要检验组成一个FDR家族。主要整体检验分别报告原始双侧P值和95%区间；一年结局单PC、纵向时间交互和单项位置交互分别为次要家族，使用BH-FDR。未检验、不可估计及已检验不显著分别编码。

首版临床协变量缺失不自动多重插补；报告各模型完整病例人数及未进入模型原因。完整病例结果不自动推广为全队列无偏因果效应。敏感性或缺失处理策略的后续更改须追加方案版本。

B3血管内治疗后出血及B4抗栓期间脑出血/缺血复发仅作交接。交付患者影像宽表、随访长表、事件表、用药快照、变量字典和缺项报告。需核查治疗及出血时间、出血分类和症状性依据、再通、围术期药物、抗栓起停换药、复发/死亡日期、肾功能及CMB/cSS。空白不是无事件；用药快照不自动生成暴露区间。

## 预期结果与记录

预期形成校准后的区域偏离、经验证的空间模式、连续联合表型、功能关联与急慢性交互估计及GB复现。允许参考不足、K=0、无额外解释能力、交互不显著或外部复现失败；这些都属于可报告结果。

每个输出带run_id、配置和代码版本。软件验证使用明确标记的合成数据；真实队列计算在远程工作站产生。截图解释必须记录来源run_id、分析编号、截图对应结果及未核实部分。旧版本结果不可因截图反馈直接覆盖。
