- 日期（Asia/Shanghai）：
- run_id / task_id / attempt_id：
- Git提交 / 配置哈希 / 输入清单哈希：
- 运行环境：本地合成验证 / 远程真实队列
- 原始输出路径及文件哈希：
- 本次执行内容：
- 成功、失败、等待、不适用的数量与分母：
- 已完成的数值或图像检查：
- 实际观察结果：
- 统计解释及其适用范围：
- 未检验、不可估计或未核实内容：
- 决策及原因：
- 是否更改方案/科学参数（若是，新版本及新run_id）：
- 下一步动作：
