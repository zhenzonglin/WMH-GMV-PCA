## 可重复命令

在项目目录执行；测试入口不自动启动真实分析：

```bash
.venv/bin/python -m pytest -q
R_LIBS="$PWD/.Rlib" Rscript tests/R/test_imaging.R
R_LIBS="$PWD/.Rlib" Rscript tests/R/test_clinical.R
.venv/bin/python scripts/make_synthetic.py --config config/synthetic_v2.yaml
bash scripts/start_project.sh --config config/local/smoke_v2/project.yaml
.venv/bin/python scripts/monitor_project.py --config config/local/smoke_v2/project.yaml --once
```

命令中的R_LIBS仅追加项目包库，保留R自带及用户库；正式远程环境需依据renv.lock重建完整依赖。已存在合成输入时不覆盖，重新生成需使用明确允许overwrite的独立配置。
