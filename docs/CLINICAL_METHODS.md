# 临床统计与交接实现

## 数据入口

Python `prepare_clinical`读取UTF-8 TSV，ID始终为字符串。影像表是左连接基准；同一临床ID重复时不任取一条。变量映射来自 `variables.clinical.fields`，可使用有序别名列表；多个别名值冲突会留档。数值重编码通过 `value_maps` 指定，不猜测“1=有/2=无”。

`clinical_wide.tsv`保存原始来源值、规范化值、来源和冲突标记。`clinical_long.tsv`保存3/6/12个月访视。`variable_audit.tsv`区分列不存在、缺失及非法值；`eligibility.tsv`报告单点、纵向和交互模型的可分析人数。

确认死亡只向后传播。例如6个月确认死亡，不填充此前未知的3个月mRS。死亡日期只有在有可比较的访视日期时才能确定当次状态；名义访视日期推算默认关闭。报告的mRS=6作为死亡证据保留来源；若与明确生存记录冲突，列入冲突表。默认排除冲突病例，不能静默修复。

## B1一年结局

使用 `ordinal::clm(link="logit")`，保留0–6等级。年龄、NIHSS使用配置指定的自然样条；其他调整变量为性别、卒中前mRS（逐分线性项）、既往卒中、高血压、糖尿病、房颤、溶栓及EVT。总量模型增加log(ICV)、log1p(WMH总量)、log(GMV总量)。中心和扫描距发病时间不进入任何模型。

M0/M1/MW/MG/MWG使用同一完整病例集。WMH和GMV成分按C3分析患者标准差缩放，模型保存缩放参数。OR>1表示较差mRS的优势增加。报告系数、Wald区间、完整模型块似然比检验和完整mRS概率；只在最终联合模型的单成分次要检验内计算BH-FDR。

连续体积协变量的log变换后也按C3均值/SD中心化标准化，保存在模型的`covariate_scaling`并用于GB和留出预测。B2的log1p急性体积同样处理。该可逆参数化保留相同拟合空间，可改善阈值与斜率的Hessian数值尺度；对应总量OR以1个C3标准差为单位，不再称原始log体积单位。不会因此放宽梯度、收敛或正定性要求。

`ordinal::nominal_test`用于比例优势诊断；满足配置阈值的项可进入单独的部分比例优势敏感性模型。敏感性结果不替换原模型，也不把阈值特异系数误称共同OR。

## B1纵向结局

`clinical_b1_longitudinal`调用 `ordinal::clmm`，访视是3/6/12月分类变量，设置患者随机截距，加入访视×空间成分。缺失访视不填充、无需三访完整；模型利用可观察记录。按配置比较两个求积点数，保存系数差异。OR为条件OR，不能解释为人群平均OR或死亡吸收转移概率。首版输出观察mRS分布，不把随机效应设零的概率伪称人群平均概率。

数值后端固定为ordinal支持的ucminf，配置中明确指定内层梯度容差1e-4、外层梯度目标1e-4、相对步长目标1e-12及最多2000次函数计算。它们是优化器终止设置；最终验收仍要求项目梯度≤0.001、有效正定Hessian及成功状态。ucminf官方成功码是1/2，nlminb是0；不能混用。零步线搜索码4不当作成功，即使当次梯度较小。失败时保存模型及diagnostic_failure.tsv，不静默改变量或放宽门槛。

`timepoint_effects.tsv`另外给出各访视的空间成分OR。3个月使用主效应β；6/12个月使用β加对应时间交互系数。标准误按完整协方差矩阵计算，包括两系数的协方差项。区间由配置alpha确定，标签为条件OR。此表为既有模型的线性对比报告，不新增P值或FDR家族；无空间成分时输出仅含表头的文件。

## B2急慢性交互

使用全部冻结空间PC主效应、急性位置主效应、总体积样条和体积×选定慢性成分。加入最多2个急性位置维度×WMH、GMV各前2个稳定成分，整体位置交互块为主要检验。上游可通过 `interaction_acute` 和 `interaction_chronic` 请求字段指定可单独识别成分，防止在近简并组中截断。个别位置交互项单独组成BH家族。

## GB与预测标签

GB必须传入C3的 `models.rds`。样条结点、成分缩放和模型公式使用C3保存值。GB自行估计相同公式得到关联复现；使用C3固定系数另输出 `GB_frozen_C3_external` 预测。相同数据拟合后预测只标为 `C3_association_apparent` 或 `GB_association_apparent`。本模块不把表观性能冒充内部验证；患者层面的完整训练折影像重拟合需由外层工作流组织。

输出有序RPS、log loss和各累积阈值校准表。独立生活概率为P(mRS≤2)。无结局或协变量时输出waiting_input；类别缺失、设计矩阵秩不足、人数相对自由度不足时输出not_estimable，不自动合并等级或删变量。优化失败抛出真实失败。

## B3/B4交接

`events.tsv`保留原始事件代码、日期及来源；空白不表示无事件。`medication_snapshots.tsv`明确标记snapshot，不生成未观察到的起停药区间。出血、药物和事件字段由配置决定；本模块不拟合B3/B4模型。

所有输出必须连同变量字典、配置和模型版本交给统计师。未校正缺失选择机制的完整病例关联不应表述为全队列无偏因果效应。
