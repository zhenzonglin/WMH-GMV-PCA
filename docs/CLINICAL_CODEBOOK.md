# 临床字段编码依据

依据用户提供的《变量需求_黄色高亮.xlsx》核对；该文件是变量字典，不是患者数据。正式病例编码仍由audit核查。

| 原始列 | 字典编码 | 规范化 |
|---|---|---|
| H_STROKE、H_HYPT、H_DIAB | 1否、2是、98不详 | 0、1、缺失 |
| H_AF | 0否、1是，属于H_HD的条件分支 | 保留0/1；空值不自动当0 |
| TPA、ET_MT、MT_RPT | 1否、2是 | 0、1 |
| I_IS_HT、I_IS_SHT | 1否、2是 | 0、1 |
| F3_DEATH、F6_DEATH、F12_DEATH | 1死亡、2存活 | 1、0 |
| IMG_SVD_CMB | 1有、2无、99不可判读 | 1、0、缺失；另保留不可判读标记 |
| IMG_SVD_CMB_cSS | 1否、2是 | 0、1 |

来源：基线/随访页第138–141、178、180、188、211、427–428、1002、1934、2807、3770行；影像页第781、832行。MT_RPT仅表示是否再通，不能冒充mTICI等级。

`source_value_maps`按实际原始列优先转换；无来源专用映射时才使用canonical的`value_maps`。因此H_HYPT=2和已经规范化的hypertension=1不会被误判为冲突。若转换后仍不同，记录冲突并按配置处理。

原始值及来源列保存在`source_<变量>`和`source_column_<变量>`；临床原始表的冻结快照一并进入统计师包。99/98等缺失代码不被改为“否”。检验指标若可能真实取99，应在`field_missing_codes`单独设置规则，不能沿用量表的缺失编码。

清洗后的m3_death/m6_death/y1_death编码未在该字典明确列出，需用实际导出值及原始死亡记录核对；不自动猜测新的编码体系。H_AF条件跳题导致的空值也需核验，可提供整理后的0/1房颤字段。

字典3741–3742、3747–3748行明确：`y1_is/y1_HS`为0否1是，`y1_is_dd/y1_HS_dd`为发病到事件的时间间隔（day），不是日历日期。因此事件表分别保留`relative_days/time_unit/time_origin`与`event_date_raw`，不能把第120天解析成日历日期。出血性卒中HS不能自动改称脑实质出血ICH。
